# ScamShield AI

ScamShield AI is an AI-powered multilingual financial scam detection system.

It analyzes suspicious financial messages using specialized detection agents and provides risk insights to help users identify potential scams.

## Features

- 🔍 Financial scam detection
- 🌐 Multilingual message analysis
- ⚠️ Risk assessment
- 🤖 Multiple specialized detection agents
- 💻 Streamlit-based web interface

## Technologies Used

- Python
- Streamlit
- AI-based detection agents
